Core Architecture

Built Without Compromise

Engineered to overcome the blind-touch vulnerabilities and rigid constraints of traditional security keys.

Dual-GATT Wireless Architecture

Complete wireless isolation. Standard FIDO service (0xFFFD) is left pure for native pairing on iOS and Android. A dedicated daemon bridge (FBF6EB80) powers full-speed OpenSSH, smart card PIV, and browser extension communication on laptops.

WYSIWYS Transaction Display

What You See Is What You Sign. By parsing relying party IDs and client data hashes directly on-chip, Cryptick displays the domain and user handle on its physical screen, eliminating blind-touch phishing attacks.

Zero-Trust Hardware TOTP Enclave

Stores hundreds of 2FA accounts encrypted at rest in LittleFS using AES-256-GCM. The token calculates RFC 6238 codes on-chip using its internal RTC. The host never touches seeds or calculates hashes.

1-Click Computer Login

Automates macOS SmartCard pairing (sc_auth / CryptoTokenKit) and Linux pam_u2f with cryptick login setup. Unlock your computer and authorize sudo commands with a single touch.

Native OpenSSH Middleware

Drop-in libsk_blebridge.dylib / .so support for OpenSSH sk-ssh-ed25519@openssh.com. Probes direct USB first, automatically falling back to wireless BLE when unplugged.

Auditable & Upgradable

Zero black-box microcontrollers. Firmware is cryptographically signed with Secure Boot v2 and upgradable over USB. Every schematic, PCB file, and daemon line is publicly available under Apache 2.0.

Technical Specifications

Production specifications for Cryptick Token PCB v0.1.0.

Microcontroller & SoC
Espressif ESP32-S3-WROOM-1 (Xtensa® Dual-Core 32-bit LX7 @ 240MHz, Vector Instructions)
Memory & Storage
16 MB Quad SPI Flash (LittleFS Encrypted Enclave) + 8 MB Octal PSRAM + 512 KB SRAM
Biometric Sensor
R558S Capacitive Optical Biometric Enclave (508 DPI, 120 Templates, Hardware Wake-on-Touch)
Physical Display
128x64 OLED (SSD1306) on Hardware I2C (Address 0x3C, SDA GPIO 8, SCL GPIO 9)
Physical Controls
5-Way Tactile Switch (UP=7, DOWN=4, LEFT=6, RIGHT=5, CENTER=15) + WS2812 RGB Neopixel (GPIO 48)
Wireless Connectivity
Bluetooth Low Energy 5.0 (Dual-GATT: Standard FIDO 0xFFFD + Daemon Bridge FBF6EB80)
Wired Interfaces
Native USB-C OTG (TinyUSB Composite: CTAPHID FIDO2, CCID Smart Card, CDC Debug Serial)
Power & Battery
Integrated TP4056 LiPo/Li-Ion Charger with Dual Status (STAT1=38, STAT2=39) + USB Bus Power
Cryptographic Algorithms
Hardware TRNG, AES-256-GCM, SHA-256, EC P-256, Ed25519, HMAC-SHA1/SHA256, RSA-3072
Compliance & Standards
FIDO Alliance CTAP 2.0 / 2.1, W3C WebAuthn Level 3, NIST SP 800-73-5 PIV, RFC 6238 OATH-TOTP
